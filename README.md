# Lakbay Kinabukasan

My second project for UCSP. It's basically a game where you travel around answering questions about Filipino values, careers, education, and being a good citizen all in one HTML file.

## How to run

Just open `index.html` in your browser. That's it. No installs, no setup, nothing.

## What's in it

- Story mode with different stations (school, TESDA training, plaza, etc.)
- Quizzes that explain why the answer is what it is
- A career picker and you gain skills as you play
- Everything is in Filipino
